# محاكي سجود السهو

الموقع: https://destivano.github.io/salah_simulator/

للنشر على GitHub Pages وربط AWS Lambda، اتبع [دليل النشر](DEPLOYMENT.md). حزمة Lambda تُبنى بالأمر `python scripts/package-lambda.py` في `dist/salah-simulator-lambda.zip` دون مفاتيح. يحتوي `config.js` على إعداد عنوان الخدمة العام فقط.

افتح `index.html` في أي متصفح — لا يحتاج تثبيتًا ولا خادمًا.

- `index.html` — الأداة كاملة (ملف واحد).
- `docs/rules.txt` — مرجع الأحكام الأصلي (المصدر الوحيد للمحتوى الفقهي).
- `tests/search.test.mjs` — اختبار محرك البحث (`node tests/search.test.mjs`).
- `CLAUDE.md` — سياق المشروع وقراراته لـ Claude Code.
- `qa-service.mjs` — منطق الأسئلة والمصادر المشترك بين الخادم المحلي وLambda.
- `lambda.mjs` — معالج AWS Lambda Function URL.

## الأسئلة الموثّقة من المصادر

للبحث المحلي والمحاكي فقط، افتح `index.html` مباشرة. لاستعمال النماذج، تحتاج Node.js إصدار ٢٢ أو أحدث واتصالًا بالإنترنت:

1. انسخ `.env.example` إلى `.env` إذا لم يكن لديك ملف مفاتيح بالفعل، واضبط `GROQ_API_KEY` و`COMMAND_CODE_API_KEY`.
2. شغّل `npm start` (أو `npm.cmd start` في PowerShell إذا كانت سياسة التنفيذ تمنع npm).
3. افتح `http://127.0.0.1:3000/#other` واختر النموذج في قسم «اسأل من مصادر المشروع».

لا تحتاج تثبيت مكتبات. يمكن أيضًا التشغيل بالأمر `node --env-file-if-exists=.env server.mjs`. يغيّر `PORT` المنفذ الافتراضي.

النماذج: GPT OSS 120B وGPT OSS 20B وQwen 3.8 27B عبر Groq، وGPT 6 Luna وKimi K3 وGLM 5.3 وDeepSeek V4 Pro عبر Command Code. يتحقق الخادم من كتالوج كل خدمة؛ ظهور النموذج في الكتالوج لا يضمن سماح خطتك باستعماله. لا يجري تبديل النموذج تلقائيًا عند الفشل.

يقرأ الخادم جميع ملفات `.txt` و`.md` داخل `docs/` عند كل سؤال ويرسل محتواها كاملًا مع السؤال والمحادثة إلى الخدمة المختارة. لا توجد قاعدة متجهات أو بحث خارجي. تُحفظ المحادثة في ذاكرة الصفحة فقط؛ إعادة تحميلها أو اختيار «محادثة جديدة» يمحوها. تغيير النموذج يُبقي السياق ويُرسله للخدمة الجديدة. الحد الحالي ستة أسئلة في المحادثة.

لكل مقطع مصدر معرف مشتق من محتواه ومساره. يعرض الجواب مراجع تفتح النص الأصلي وموضعه في الملف وقت السؤال. تُرفض المراجع غير الموجودة والأجوبة المصنّفة كإجابة دون مراجع؛ يُطلب التصحيح مرة واحدة من النموذج نفسه عند فشل الصيغة أو المراجع، وقد يستهلك ذلك طلبًا إضافيًا. هذا الفحص لا يثبت أن النص يدعم كل استنتاج؛ راجع المصادر، خصوصًا ملاحظات المراجعة في الأصل. لا يعدّل النظام أحكام المصادر أو المحاكي.

المفاتيح تبقى في الخادم، وملف `.env` مستثنى من Git. الخادم يتيح الصفحة وواجهتي API فقط، ويستمع على الجهاز المحلي مع رفض الطلبات من مواقع أخرى. هذه نسخة محلية؛ النشر العام يحتاج مصادقة وضبط حصص الاستخدام قبل إتاحة مفاتيحك للزوار.

## التحقق

عند بلوغ حد الخدمة وإرسال مهلة انتظار لا تتجاوز دقيقة، تعرض الواجهة عدًّا تنازليًا وتعيد السؤال مرة واحدة مع السياق نفسه. لا تُحتسب المحاولة الفاشلة سؤالًا جديدًا ولا تُمسح المحادثة. الحدود تشمل المصادر الكاملة المرسلة مع كل سؤال؛ الانتظار يتم في المتصفح، وليس داخل Lambda.

- `npm test` أو `npm.cmd test`: اختبارات البحث، تحميل المصادر، المراجع، المدخلات وحماية واجهات الخادم. لا تستعمل مفاتيح أو طلبات مدفوعة.
- `node tests/live-qa.mjs`: اختبار اختياري لكل نموذج، يحتاج خادمًا جاريًا ومفاتيح فعلية ويستهلك رصيد الخدمات.
- `tests/qa-evaluation.json`: أمثلة للمراجعة اليدوية لجودة الأجوبة. نجاح الاختبارات البرمجية وحده لا يثبت صحة الأجوبة الفقهية.

تفاصيل الاتصال: [Groq](https://console.groq.com/docs/openai)، [Command Code](https://commandcode.ai/docs/provider).
